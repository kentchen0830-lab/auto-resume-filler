# Privacy

本项目处理的核心数据是简历信息，因此隐私优先级高于自动化便利性。

## 本地数据

简历数据、用户设置和 API Key 通过浏览器扩展的 `chrome.storage.local` 保存在当前浏览器配置中。它们不会被 GitHub 仓库自动收集，也不会由本项目自建服务器接收。

## 可选 AI 请求

只有用户主动启用 AI 模式时，扩展才会向配置的 AI API 发起请求。代码会尽量排除身份证、手机号、邮箱、住址、密码、验证码、Token、API Key 等敏感字段，并对常见敏感值模式进行替换。

过滤机制并非绝对可靠。启用 AI 前，用户仍应检查页面内容和简历数据，确认没有不希望发送给第三方服务的信息。

## 页面访问

为了识别不同招聘网站的表单，扩展会在网页上下文中读取可见的输入控件和相关标签。不要在网银、邮箱后台、密码管理器等非招聘场景页面使用本扩展。

## 日志与导出

导出的规划 JSON 可能包含岗位描述和非敏感简历内容。请把导出文件视为私人资料，不要提交到公开仓库。
